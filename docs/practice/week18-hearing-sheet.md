# 練習課題1：ヒアリングシート

架空のクライアント「○○酒造」から、EC サイト制作の相談を受けた想定で作成したヒアリングシートです。

## クライアントの設定（架空）

| 項目 | 内容 |
|---|---|
| クライアント | ○○酒造（架空の酒蔵） |
| 規模 | 家族経営、従業員5人 |
| 今の売り先 | 地元のお店、蔵の直売所、スーパー |
| 依頼人 | 蔵元（社長）。昔からのやり方を大事にしていて、パソコンは苦手 |
| 依頼内容 | 「うちの日本酒を、ネットでも買えるようにしたい」 |

## ヒアリング前の準備（チェックリスト）

| チェック項目 | ○○酒造の場合 |
|---|---|
| □ ビジネス背景の調査 | ○○酒造のお酒の種類や、地元での評判を調べる |
| □ 業界・競合の理解 | 他の酒蔵の EC サイト、大手通販サイトでの日本酒の売られ方、写真・デザインの見せ方、お酒のネット販売の法律を調べる |
| □ 質問リストの作成 | 下の「質問リスト」を用意する |
| □ 参加者の確認 | 社長に加えて、サイトを動かす担当になりそうな従業員（パソコンがある程度できる人）にも参加してもらう |
| □ 時間・場所の調整 | 酒蔵に直接行く（パソコンが苦手な相手には、リモートだと伝わりにくいため）。酒造りが忙しい時期（一般的に秋〜冬）を避ける |
| □ 録音・記録の許可取得 | 最初に、録音してよいか社長に確認する |

## ヒアリングシート

### ■ プロジェクト概要
- プロジェクト名：○○酒造 EC サイト制作
- ヒアリング日時：（酒造りが忙しい時期を避けて調整）
- 参加者：社長、サイト担当予定の従業員、自分（制作者）
- 目的：EC サイトで解決したい課題と、成功の基準を明らかにする

### ■ 現状の課題

**質問の流れ**

| タイプ | 質問 | 想定される回答 |
|---|---|---|
| オープン | 今、お酒を売るときに困っていることはありますか？ | 最近、地元の酒屋さんが減ってねぇ… |
| 深掘り | 今は、どこで一番よく売れていますか？ | 直売所かな。観光で来た人がよく買ってくれるよ |
| 確認 | つまり、観光の人は家に帰ったら買えないということですね？ | そうそう！「また飲みたい」って電話が来ることもあるんだよ |
| クローズド | 今、電話やメールで注文を受けて、発送することはありますか？ | たまにあるね |
| 深掘り | その注文は、どのように受けて、どうやって送っていますか？ | 電話で聞いてメモして、振込を確認してから宅配便で送ってる |
| オープン | ほかに、手間がかかっていることはありますか？ | 電話注文は聞き間違いが怖いし、仕込みの最中だと出られないんだよ |

**整理**
- 業務フロー：電話で注文を受ける → メモする → 振込を確認する → 宅配便で発送する
- 課題点：
  - 地元の酒屋さんが減って、売る場所が少なくなっている
  - 観光客がリピートしたくても、家に帰ると買えない
  - 電話注文は、聞き間違いや、仕込み中に出られないことがある
- 解決したいこと：遠くの人でも、いつでも注文できるようにしたい

### ■ 目指す姿

| タイプ | 質問 | 想定される回答 |
|---|---|---|
| オープン | ネットで買えるようになったら、どんな人に、どんなふうに買ってほしいですか？ | 一度飲んでくれた人に、また買ってほしいね |
| 深掘り | 例えば、どの地域の人に届けたいですか？ | 観光で来てくれた人の地元、全国かな |
| オープン | ネットで売れるようになったら、お店にとって何がいちばんうれしいですか？ | 酒屋さんが減った分を補えるとありがたい |
| クローズド | 1年後、ネットで月に何本売れたらうれしいですか？ | 月に50本くらい売れたらうれしいね |
| 確認 | では、1年後に月50本を目標にする、ということでよろしいですか？ | それでお願いします |

**整理**
- システム導入後の理想：直売所で買ってくれた観光客が、家に帰ってからもネットでリピートしてくれる
- 期待する効果：地元の酒屋さんが減った分の売り上げを補う。電話注文の手間を減らす
- 成功の基準：1年後に、ネットで月50本売れる

### ■ 制約条件

| 項目 | タイプ | 質問 | 想定される回答 |
|---|---|---|---|
| 予算 | クローズド | ご予算は、だいたいどれくらいをお考えですか？ 例えば〇〇万円くらいでしょうか？ | あまりかけられないけど、30万円くらいかな |
| 納期 | オープン | いつごろから、ネットで売り始めたいですか？ | できれば年内には始めたいね |
| 納期 | 深掘り | その時期に、何かきっかけ（新酒の時期・お歳暮など）がありますか？ | お歳暮の時期に間に合うとうれしい |
| 技術的制約 | クローズド | お店にパソコンやスマホ、インターネットの環境はありますか？ | 事務所にパソコンが1台ある。娘がたまに使ってるよ |
| 法律・規制 | クローズド | ネットでお酒を売るには、お酒を造る免許とは別の免許が必要になることがあるんです。もうお持ちですか？ まだでしたら、一緒に確認していきましょう | それは知らなかったな… |
| 法律・規制 | オープン | 20歳未満の人には売れないので、年齢を確認する方法を考える必要があります。お店では、今どのように確認していますか？ | 直売所では、若そうな人には声をかけて確認してるよ |

**整理**
- 予算：30万円程度
- 納期：お歳暮の時期までに販売を始めたい
- 技術的制約：事務所にパソコンが1台。サイトの更新は、パソコンを使える従業員が担当する想定
- 法律・規制：
  - 通信販売の免許が必要かを、税務署に確認する（免許の取得には時間がかかる可能性があるため、納期に影響する）
  - 20歳未満には販売できないため、注文時に年齢を確認する仕組みが必要

## ヒアリングで工夫したこと

- 社長はパソコンが苦手なので、専門用語を使わず、「売り上げ」より「どこで一番よく売れていますか」のように、やわらかい言葉で聞く
- 成功の基準は「1年後」「月に何本」のように、期限と数字で答えてもらう。「本」は社長がいつも使っている単位なので、イメージしやすい
- お金や期限の話は身構えられやすいので、課題・理想を聞いて打ち解けてから、最後に聞く
- 免許のように相手が知らないかもしれないことは、「まだでしたら一緒に確認しましょう」と添えて、正直に答えやすくする
