# 練習課題3：要件整理

練習課題1・2の架空のクライアント「○○酒造」の社長から出た曖昧な要求を、明確な要件に整理したものです。

## 考え方

- **曖昧な要求**：「見やすく」「すぐ」「簡単に」など、人によって意味が変わる言葉が入っている
- **明確な要件**：誰が読んでも同じ意味になり、できたかどうかを確かめられる（INVEST 原則の T：Testable）
- 自分で決められないことは勝手に決めず、「確認すること」としてクライアントに聞く

## 整理した要件

### 1. 「スマホでも見やすくしてほしいな」

**明確な要件**
- 本文の文字の大きさは 16px 以上にする
- スマホを縦向き・横向きどちらにしても、横にスクロールしなくても全部見える

**確かめ方**
- ブラウザの開発者ツールで、文字の大きさを確認する
- スマホで開いて、縦向き・横向きにして確認する

### 2. 「注文が来たら、すぐ分かるようにしてほしい」

**明確な要件**
- 注文が確定したら、自動でメールを送る
- 送り先：サイト担当の従業員の会社のメールアドレス
- メールには、注文番号・商品・個数・お届け先を書く

**確認すること**
- 「すぐ」は、注文の直後でよいか
- 社長にもメールを送るか

**整理のポイント**
- ヒアリングで分かった「社長はパソコンが苦手」「サイトを動かすのは従業員」「仕込み中は電話に出られない」から、知らせる相手と方法を考えた

### 3. 「おしゃれなサイトにしてほしい」

**明確な要件**
- 色は、蔵のイメージに合わせて3色以内にする（メインの色・アクセントの色・背景の色）
- トップページの一番上に、蔵や商品の大きな写真を1枚表示する
- 商品の写真は、すべて同じ背景・同じ大きさで撮影したものを使う

**確認すること**
- 「おしゃれ」のイメージに近いサイトを、他の酒蔵のサイトなどから2〜3個選んでもらう
- 蔵のイメージに合う色（ラベルや看板の色など）はあるか

**整理のポイント**
- 「おしゃれ」は人によって一番イメージがちがう言葉なので、言葉で決めるより、参考になるサイトを見せてもらうほうが確実

### 4. 「簡単に買えるようにしてほしい」

**明確な要件**
- 商品詳細ページから、3回以内の画面移動で注文が完了する（商品詳細 → カート → 注文情報の入力・確認 → 完了）
- 会員登録をしなくても注文できる
- 会員は、お届け先が自動で入力される

**確認すること**
- 支払い方法は何を使えるようにするか（クレジットカード・銀行振込・代金引換 など）

**整理のポイント**
- 「簡単」を「画面移動の回数」と「入力の手間」の2つに分けて、数えられる形にした

### 5. 「安心して買ってもらえるようにしたい」

**明確な要件**
- すべてのページを HTTPS で表示する
- 特定商取引法に基づく表記（販売者名・住所・連絡先・送料・返品について）のページを作る
- 蔵の紹介ページ（歴史・造り手・お酒へのこだわり）を作る
- 注文時に、20歳以上であることを確認する画面を表示する

**確認すること**
- 返品・交換を受け付けるか、受け付ける場合の条件
- 通信販売の免許が必要か（税務署に確認する）

**整理のポイント**
- 練習課題2で考えた「初めて買うお店が信頼できるか確かめたい」（US-05）と、法律による要件（US-16）につなげた

## まとめ：曖昧な言葉を明確にするコツ

| 曖昧な言葉 | 明確にする方法 |
|---|---|
| 見やすい | 文字の大きさなど、数字で決める |
| すぐ | 「注文の直後」など、タイミングを決める |
| おしゃれ | 参考のサイトを見せてもらう |
| 簡単 | 画面移動の回数や入力の手間を数える |
| 安心 | 必要なページや確認画面など、具体的に何を用意するか決める |
