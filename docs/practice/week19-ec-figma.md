## 題材

**「○○酒造」のオンラインショップ**（架空）

Week 18 の練習課題で作った [ヒアリングシート](week18-hearing-sheet.md) と [ユーザーストーリー](week18-user-stories.md) の続きとして、EC サイトの画面を設計した。

## 設計の方針

- **ワイヤーフレーム**（白黒・枠のみ）で作る
- **PC（Desktop 1440×1024）** で作る。日本酒は価格や説明を見比べてじっくり選ぶ商品のため、PC で買う人も多いと考えた（oshi-tomo はスマートフォンで作ったため、両方のサイズを練習する目的もある）
- お酒を売るサイトのため、**20歳未満には販売しないこと** を、全画面の上部と、購入ボタンの近くに表示する

| 03 | 商品詳細 | 写真（メイン＋小さい写真4枚）、価格、送料とお届け日数、数量、カートに入れる、年齢確認の注意、商品の説明 | US-03, US-04, US-06, US-16 |

## 画面遷移

| どの画面の | 何を押すと | どの画面へ |
|-----------|-----------|-----------|
| 01 トップページ | 「商品を見る」ボタン、ヘッダーの「商品一覧」 | 02 商品一覧 |
| 01 トップページ | ジャンルのボタン（純米酒など） | 02 商品一覧（そのジャンルで絞り込んだ状態） |
| 01 トップページ | 検索 | 02 商品一覧（検索結果） |
| 01 トップページ | おすすめ商品のカード | 03 商品詳細 |
| 02 商品一覧 | 商品カード | 03 商品詳細 |
| 03 商品詳細 | パンくずの「商品一覧」 | 02 商品一覧 |
| すべての画面 | ヘッダーの「○○酒造」、パンくずの「トップ」 | 01 トップページ |

## 工夫したところ

| 工夫 | 理由 |
|------|------|
| 検索（US-01）とジャンル（US-02）を両方置いた | 欲しいお酒が決まっている人と、見ているだけの人の両方が探しやすいように |
| トップに「蔵の紹介」を置いた（US-05） | 初めて聞く小さな酒蔵からネットで買うのは不安なため、信頼してもらえるように |
| 商品詳細に送料とお届け日数を書いた（US-04） | 合計いくらで、いつ届くかが分かってから買えるように |
| 売り切れの商品に赤字で「売り切れ」と表示した（US-13） | 買えない商品をカートに入れてしまわないように |
| フッターに「特定商取引法に基づく表記」を置いた | ネットで商品を売るお店に、法律で表示が必要なため |

## チェックリスト（教材）

| チェック項目 | 対応 |
|-------------|------|
| ユーザー導線が明確か | トップ → 商品一覧 → 商品詳細 → カートの流れで、どの画面からも次へ進めるボタンがある |
| 必要な情報が揃っているか | 商品名・写真・価格・容量・送料・お届け日数・原料米などを商品詳細にまとめた |
| ボタン配置は適切か | 一番押してほしい「カートに入れる」を、価格のすぐ下に大きく濃い色で置いた |
| レスポンシブ対応を考慮したか | PC で作成。スマートフォンでは、商品カードを1〜2列にし、左の絞り込みは「絞り込み」ボタンで開く形にする |
| アクセシビリティに配慮したか | 売り切れは色だけでなく「売り切れ」の文字でも表示した |
| エラー表示を設計したか | 在庫より多い数量を選んだときは、数量の下に赤字で表示する（今回のワイヤーフレームには描いていない） |
| ローディング状態を考慮したか | カートに入れる操作中は、ボタンを押せないようにして二重に入るのを防ぐ |
