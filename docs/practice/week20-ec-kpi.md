# 練習課題2：KPI設定

Week 18 の架空のクライアント「○○酒造」の EC サイトについて、KPI を3つ設定したものです。

## 1. ゴール（KGI）

**1年後に、ネットで月50本売れる**（[week18-hearing-sheet.md](week18-hearing-sheet.md) の「成功の基準」）

KGI（最終的なゴールの数字）だけを見ていても、届かないときに何が悪いのか分からない。そこで、50本を分解して、途中の数字（KPI）にする。

## 2. 50本を分解する

```
月の販売本数 ＝ 月間訪問者数 × コンバージョン率 × 1回の注文の本数
    50本     ＝    1,250人   ×       2%        ×      2本
```

| 数字 | 決め方 |
|------|--------|
| 1回の注文の本数：2本 | 送料がかかるため、まとめ買い（自分用＋贈り物など）が多いと考えた |
| コンバージョン率：2% | EC サイトでよく言われる平均（1〜3%）の真ん中 |
| 月間訪問者数：1,250人 | 50本 ÷ 2本 ＝ 25件の注文。25件 ÷ 2% ＝ 1,250人 |

## 3. KPI

### KPI ①：月間訪問者数

| 項目 | 内容 |
|------|------|
| 種類 | ユーザー獲得 |
| 目標 | 1年後に **月1,250人** |
| 中間目標 | 3か月後 300人、6か月後 700人 |
| 選んだ理由 | まずサイトに来てもらわないと、商品は売れないため |
| 測り方 | Google Analytics で、1か月の訪問者数（ユーザー数）を見る |
| 届かないときの行動 | 直売所でサイトの QR コードが入ったカードを配る。商品の発送時にもカードを同封する |

### KPI ②：コンバージョン率

| 項目 | 内容 |
|------|------|
| 種類 | 収益 |
| 目標 | **2%** |
| 選んだ理由 | 来た人がちゃんと買えているか（商品ページが分かりやすいか、注文の手順で迷っていないか）が分かるため |
| 測り方 | 1か月の注文の件数 ÷ 1か月の訪問者数 × 100（注文の件数は、管理画面の注文一覧から数える） |
| 届かないときの行動 | Google Analytics で、どの画面で帰ってしまう人が多いかを見る。カートや注文の入力で多ければ、入力の項目を減らす。商品ページで多ければ、写真や味の説明を増やす |

### KPI ③：リピート購入率

| 項目 | 内容 |
|------|------|
| 種類 | エンゲージメント |
| 目標 | **30%** |
| 選んだ理由 | ○○酒造がネットで売る一番の理由は、ヒアリングで分かった「観光客が家に帰ってもリピートしたい」という課題を解決すること。その課題が解決できているかが分かるため |
| 測り方 | 1か月の注文のうち、前にも注文したことがあるメールアドレスからの注文の割合（会員登録なしでも注文できるため、メールアドレスで判断する） |
| 届かないときの行動 | 次の段階の機能（会員登録・購入履歴、2回目に使えるクーポン）を前倒しで提案する。新酒の時期に、前に買ってくれた人へお知らせのメールを送る |

## 4. KPI の確認の仕方

- **毎月1回**、店の担当者と3つの数字を確認する
- 社長はパソコンが苦手なため、数字は表1枚にまとめて、「先月より増えた・減った」が分かる形で伝える
- 3つの KPI が目標に届いていても月50本に届かないときは、「1回の注文の本数」が少ないと分かる。そのときは、飲み比べセットなど、まとめて買いやすい商品を提案する

## 5. KPI を測るために、サイトに必要なもの

| KPI | 必要なもの | どのスプリントで作るか（[week20-ec-sprint-plan.md](week20-ec-sprint-plan.md)） |
|-----|-----------|------|
| ① 月間訪問者数 | Google Analytics の設定 | スプリント3（デプロイのとき） |
| ② コンバージョン率 | 注文の件数が分かる注文一覧 | スプリント3（US-14） |
| ③ リピート購入率 | 注文にメールアドレスを保存する | スプリント2（US-07） |
